A week of Rust on the Linux desktop

By Sam Rivera · 6 min read

I spent a week building a small tray utility in Rust, and most of it went into reading. The zbus repository on GitHub answered more questions than any tutorial, and the API reference on docs.rs filled in the rest.

Packaging was the part I expected to hate. The LWN write-up on desktop packaging is the best overview I have found, and the notify crate made the file watching a one-afternoon job.

Every project link I opened this week went to a different browser profile: work issues in one, reading in another.

For the user interface I settled on Qt, mostly for the Kirigami tutorials, and kept a list of open questions in a GitLab issue tracker.
